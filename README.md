# -Python-ARDL-Growth-Model
Python/statsmodels replication of an ARDL bounds-testing analysis of how GFCF and Gross Domestic Savings drive GDP growth in India (1990–2025) — unit root tests, ARDL(1,0,0), Pesaran-Shin-Smith bounds test, ECM, and full diagnostics (BPG, BG-LM, JB, VIF, RESET), reproducing a CIA-I Applied Econometrics paper originally built in EViews.
